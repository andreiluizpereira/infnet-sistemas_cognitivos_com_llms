# Promob - Requisitos do computador

há 1 ano Atualizado

Os dados aqui informados pela Promob têm apenas a finalidade de servir como auxílio no momento da escolha do equipamento ideal, visando a melhor performance do Promob.  
   
Você pode contatar o seu técnico de informática para este auxiliar na escolha do equipamento que melhor se enquadram nos requisitos informados.

  

**IMPORTANTE**: 

-   Os requisitos mínimos representam o equipamento mais básico capaz de executar o Promob, porém podem ser apresentadas lentidões durante o uso.
-   Os requisitos recomendados são os que a Promob recomenda para se ter uma experiência adequada na utilização do software.

**IMPORTANTE**

-   O Promob não pode ser executado em máquinas virtuais.
-   A instalação do Promob não pode ser realizada em uma unidade de rede.
-   O Promob não é compatível com Windows Server.
-   Recomendamos que o Windows esteja em dia com as atualizações disponibilizadas pelo Windows Update.
-   O Windows deve estar legalizado para que o Promob tenha um melhor desempenho.
-   Caso possua um antivírus instalado, configure o mesmo para que não bloqueie as pastas do Promob.
-   A Microsoft não presta mais suporte e não disponibiliza atualizações para o Windows 7 desde 2020, neste caso esta versão do sistema operacional não atende aos requisitos.
-   O Promob não é compatível com sistema operacional MAC.
